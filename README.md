# Embers, What can be expected?
 The current build is a simple demo, there isn't much in terms of gameplay yet but this is just a tiny glimpse at what could be :3
 
## Gameplay:
- All actions must be on beat, movement and shooting.
- All enemies also spawn and move on beat.
- The size of the blast depends on accuracy of timing (doesn’t shoot on miss), all aiming is still done with the mouse.
- Speed of move depends on the accuracy of the timing (doesn’t move on miss).
- Multiple inputs can be done per beat, (i.e. moving left and shooting on the same note)
- Controls:
- All movement is on tiles, the player and the enemies, one tile per beat, (maybe only the player can do hold notes though? As an advantage?)
- Players can shoot enemies anywhere on the map, maybe bullets will pierce, maybe not.
- Maybe different types of attacks depending on the specific beat?
- Maybe add a dash for the player to have more speed over enemies (could also add hold notes at times the player will need to get away quickly).

## Levels:
- Charts will be one song length and will consist of enemies spawning and chasing the player, the player will either take damage or insta-die on enemy contact, (enemies don't go on players tile, just bump into them)
- Level editor where you can create a set of notes and when in the song they are, but it also allows you to set what enemies do on each note ( whether it be where to spawn new enemies or have the current enemies move toward the player).
- A boss level that would have special attacks (finally using Casino Rave!).

## UI:
- A nice main menu with tweening.
- Mouse cursor will show when notes are with a UI visual.
- A level editor that is intuitive and easy to use.

## Game Assets:
- The map is a black area of void with bright glowing blue lines outlining the tiles
- Player is a bright white square
- Enemies are bright red squares
- Laser is a big bright raygun type particle effect.
- ^^^ (All up to change)
